# Boundaries

## Owns

- clinical-trial matching logic
- eligibility evidence services
- trial ingestion and review domain assets
- React compatibility extracts for matching workspaces

## Does Not Own

- general reasoning control plane
- Foundry extension logic
- Leafy Hospital shell
- non-trial patient workflow surfaces

## Stable Interfaces

- `solution-library.manifest.json`
- extracted backend services under `backend/src/clinical_trial_matching_agent/leafy_extract`
- React compatibility extract under `frontend/leafy-react-compat`
